Claude Code v2.1.132 (May 6, post-conference)

`CLAUDE_CODE_SESSION_ID` is now injected into every Bash tool subprocess environment — enables audit-trail hooks to correlate every shell command to its originating session without manual instrumentation. `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` lets terminals that mishandle the fullscreen renderer opt out. Critical fixes: unbounded memory growth with MCP stdio servers (high-priority for long-running MCP sessions); parallel shell tool calls no longer cancel sibling reads when one fails; NFD-accented characters no longer corrupt in vim mode; pasting text starting with `/` no longer silently swallows input.

MCP Token Theft via ~/.claude.json — Mitiga Research

Mitiga security researchers disclosed a MitM attack chain against Claude Code's MCP subsystem: inject a malicious entry into `~/.claude.json`, silently redirect MCP traffic, capture OAuth tokens for connected SaaS platforms, and maintain persistent access with no visible indicator to the user. Reported to Anthropic on April 10, 2026; Anthropic responded April 12 — 'out of scope.' Covered by SecurityWeek and circulating on HN. Practical takeaway: audit your `~/.claude.json` MCP server entries, especially after installing skills or plugins from unknown sources.
