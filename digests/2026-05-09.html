Snyk for Claude Code

Announced May 8: Snyk embedded Anthropic's Claude into the Snyk AI Security Platform via MCP. One command wires Snyk's scanner into Claude Code; Claude then auto-discovers vulnerabilities in code it generates and produces developer-ready fixes, with Claude's reasoning powering both detection and remediation. Enterprise tier adds Evo by Snyk — discovers every AI asset across the org (models, agents, MCP servers, datasets), red-teams running agents for prompt injection and data exfiltration, and enforces runtime policy on tool calls before damage occurs. Requires Snyk CLI v1.1298.0+.
