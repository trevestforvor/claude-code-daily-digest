RTK — Rust Token Killer (rtk-ai)

45.5K stars. Single Rust binary (zero dependencies) that sits between Claude Code and the shell — intercepts stdout from 100+ commands (git, npm, cargo, pytest, docker, kubectl, AWS CLI) and compresses it 60–90% before it reaches the model. A 45-line `ls` output (~800 tokens) becomes 12 lines (~150 tokens); `git push` shrinks from 200 tokens to 10 tokens. v0.39.0 shipped May 6; `rtk gain` shows cumulative token savings across all sessions.
