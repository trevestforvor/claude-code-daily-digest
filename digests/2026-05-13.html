Playwright CLI (Microsoft)

v0.1.13, released May 7, 2026 — 10.3K stars. Microsoft's token-efficient browser automation CLI purpose-built for coding agents. Claude Code uses it through the Bash tool exactly like git or npm, with no extra configuration needed.

MCP OAuth Token Theft — Mitiga Research

Mitiga Labs disclosed an attack chain that silently steals Claude Code's OAuth tokens via malicious npm packages. A postinstall hook rewrites `~/.claude.json` to redirect MCP traffic through an attacker-controlled proxy; every time Claude Code initializes or refreshes a Managed Agents session, the token transits to the attacker. If the user rotates the token, the hook rewrites the config again on next load — achieving persistence. Requests still appear legitimate in SaaS audit logs. Reported to Anthropic April 10, 2026; Anthropic replied April 12 that it was 'out of scope'. Covered this week by SecurityWeek, eSecurity Planet, and CXO Digital Pulse. Mitigation: audit `~/.claude.json` for unexpected MCP URLs and avoid untrusted npm packages.

Also: www.securityweek.com/claude-code-oauth-tokens-can-be-stolen-through-stealthy-mcp-hijacking/
