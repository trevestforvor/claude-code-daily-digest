MCP OAuth Token Theft — Mitiga Research

Mitiga Labs disclosed an attack chain that silently steals Claude Code's OAuth tokens via malicious npm packages. A postinstall hook rewrites `~/.claude.json` to redirect MCP traffic through an attacker-controlled proxy; persistence survives token rotations by re-writing the config on next load. Reported to Anthropic April 10; Anthropic replied April 12 that it was 'out of scope'. No fix shipped. Mitigation: audit `~/.claude.json` for unexpected MCP URLs before any npm install.
