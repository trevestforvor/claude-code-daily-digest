Chrome DevTools MCP v1.0 (ChromeDevTools)

The Chrome DevTools team at Google shipped v1.0.0 stable yesterday (May 18) — going from 0.x to a declared-stable 1.0 after 50 releases and 40K GitHub stars. The official MCP server gives coding agents 40+ tools: full browser control, Lighthouse performance audits, network monitoring, heap snapshots, screenshots, console inspection, and extension debugging, all over the Chrome DevTools Protocol. Unlike community Playwright wrappers, this is maintained by the same team that ships Chrome DevTools itself.

Also: developer.chrome.com/blog/chrome-devtools-mcp

Anthropic Acquires Stainless (~$300M)

Announced May 18 for a reported $300M+. Stainless (NYC, founded 2022 by ex-Stripe engineer Alex Rattray) auto-generates and maintains production-quality SDKs — TypeScript, Python, Go, Java, Kotlin, and Swift — directly from an OpenAPI spec. OpenAI, Google, and Cloudflare all use it today. Post-acquisition, Anthropic is shutting down all hosted Stainless products: existing customers keep the SDKs they've already generated, but new access is Anthropic-exclusive. The Claude API's own Python and TypeScript SDKs were built with Stainless, and tighter integration is expected soon.

andrej-karpathy-skills (forrestchang)

137K stars on the original repo, 220K combined including the multica-ai mirror — a TechTimes article on May 18 called out the milestone. Forrest Chang's single CLAUDE.md encodes four behavioral rules derived from Andrej Karpathy's January 2026 post about switching to 80% agent-driven coding: Think Before Coding (state assumptions first), Simplicity First (minimum code that solves the problem), Surgical Changes (touch only what the request requires), and Goal-Driven Execution (convert vague prompts to verifiable success criteria before starting). No dependencies; installs as a plugin or drops straight into any project root.

claude-peers-mcp (louislva)

2K stars. Installs a local broker daemon on localhost:7899 (SQLite-backed) that every Claude Code session on your machine registers with. From any session you can call `list_peers` to see all active Claude instances with auto-generated work summaries, then `send_message` to forward context — a task that one agent finishes can instantly hand off state to another without copy-paste. Everything is localhost-only; no data leaves the machine. Built in TypeScript with Bun; requires Claude Code v2.1.80+.

SurgeGraph Agent Bundle (pp-surgegraph)

Launched May 19. SurgeGraph — an Answer Engine Optimization (AEO) and Generative Engine Optimization (GEO) platform — is the first dedicated AI-search SEO tool to ship a full agent-callable bundle: a single Go binary CLI, an MCP server, and a Claude Code skill, all in one package. Exposes every SurgeGraph workflow (content research, draft, publish, AI citation monitoring) to Claude Code and Codex as Bash-tool commands. Includes a local SQLite mirror of SurgeGraph data so agents can run compound queries offline without round-tripping to the API. Available through the Printing Press community library at printingpress.dev under `pp-surgegraph`.
