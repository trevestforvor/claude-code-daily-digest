Claude Code v2.1.147–148 (May 21–22)

v2.1.147 (May 21) is the biggest single-release changelog in weeks: `/simplify` is gone, replaced by `/code-review [effort]` — pass `/code-review high` for thoroughness, add `--comment` to post findings directly as inline GitHub PR comments. Pinned background sessions (`Ctrl+T`) now survive idle periods and restart in place for updates. Enterprise login restrictions (`forceLoginOrgUUID`, `forceLoginMethod`) were silently not enforced against API-key sessions — now fixed. 30+ additional fixes including pasted text no longer arriving as `[Pasted text #N]` placeholders. v2.1.148 (May 22) hotfixes a Bash exit-code-127 regression from 147.

CARL — Context Augmentation & Reinforcement Layer

334 stars; v2.0.0 (March 23, 2026) rewrote CARL around a unified `carl.json` + integrated MCP server. Static CLAUDE.md loads every rule on every message; CARL only loads rules that match the current task via keyword triggers — claimed 50% token reduction with better outputs because every injected rule is relevant. Global rules load unconditionally; domain rules surface on-demand. Covered by Charlie Automates as a core part of the "SEED + PAUL" production meta for Claude Code. Works on Mac, Windows, Linux.
