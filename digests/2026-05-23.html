WOZCODE (WithWoz)

v0.3.71 shipped May 22 — the day of this digest. YCombinator-backed, official Anthropic-approved plugin that reduces Claude Code token burn by 25–55%. Root cause: vanilla Claude runs 9+ tool calls for a 'find and edit 3 files' task (3× Glob/Grep + 3× Read + 3× Edit); WOZCODE collapses that to 2 (1× Search + 1× batch Edit) by replacing built-in file tools with optimized alternatives. Savings compound over long sessions. Runs entirely against your existing Claude subscription.

lean-ctx (LeanCTX)

v3.6.16 released May 22 (same day as this digest). 2.1k stars. LeanCTX is a local Rust binary that sits between Claude Code and your filesystem: 51+ MCP tools, Tree-sitter AST-aware compression across 21 languages, 95+ shell output stripping patterns, and cross-session property-graph memory. Benchmarks show file read tokens shrinking from ~2,000 to ~13; shell output savings up to 99%. Zero telemetry. Works with Claude Code, Cursor, Copilot, Windsurf, and 24 other agents.

Superpowers (obra / Jesse Vincent)

204K GitHub stars. v5.1.0 (May 4). Jesse Vincent's agentic skills framework — 14 composable SKILL.md files covering TDD (test-driven-development), systematic-debugging, verification-before-completion, brainstorming, subagent-driven-development, requesting-code-review, using-git-worktrees, and writing-skills. Masko Code

A living mascot companion for your Claude Code terminal. Masko watches your sessions in real time: permission prompts surface as speech bubbles (press ⌘1 to approve), ⌘M jumps to the right terminal, and double-tap ⌘ switches between sessions. Ships with Clippy and other mascots; community adds new ones daily and masko.ai generates custom ones. Hooks install automatically on first launch.
