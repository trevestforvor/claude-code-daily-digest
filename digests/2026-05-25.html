Codex Plugin for Claude Code (OpenAI)

OpenAI's official plugin that wires Codex into Claude Code — the first public case of one vendor shipping a first-party extension into a direct competitor's CLI. Three commands: /codex:review (read-only critique), /codex:adversarial-review (assumes the code is broken and hunts 7 attack surfaces: auth flaws, data loss, rollbacks, race conditions, degraded dependencies, version skew, and observability gaps), /codex:rescue (delegates full tasks to Codex in background). TechWithTim posted a head-to-head comparison video 3 days ago; Chase AI published a setup guide this week.

Also: www.chaseai.io/blog/claude-code-codex-plugin · www.youtube.com/watch?v=E2UgYp2vh5U
