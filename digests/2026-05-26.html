CodeGraph (colbymchenry)

26.6k stars, +14k in one week (AI Weekly). Builds a pre-indexed SQLite-backed symbol graph and call graph of your codebase, then exposes it to Claude Code via an MCP server. Benchmarked across 6 real-world repos: 92% fewer tool calls and 71% faster exploration on average. 100% local, 19+ languages, framework-aware route detection for 13 frameworks, auto-syncs via native OS file watchers. Works with Claude Code, Codex, Cursor, OpenCode, and Hermes Agent — no external API key required.
