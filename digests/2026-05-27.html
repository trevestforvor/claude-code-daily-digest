Security-Guidance Plugin (Anthropic)

Shipped today (May 27) to all plans at no cost. Three-level review: (1) deterministic pattern match on every file edit — no model call, flags 25 dangerous constructs including eval(), os.system(), child_process.exec(), pickle deserialization, and dangerouslySetInnerHTML; (2) model-call review after each turn; (3) pre-commit hook scan. Org-specific rules configurable via claude-security-guidance.md. Internal rollout showed 30–40% reduction in security-related PR comments. Announced alongside the Claude Managed Agents sandbox expansion.

Claude Code v2.1.152 (May 27)

Released today — the largest single-release changelog in weeks.
