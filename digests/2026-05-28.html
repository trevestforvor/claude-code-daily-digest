NanoClaw (nanocoai)

29.5k stars, v2.0.64. Containerized Claude agent runtime that replaces OpenClaw's half-million lines of code with a compact binary — each agent group runs in its own Linux container with filesystem isolation, so a compromised agent can't touch your host. Ships native connectors for 13 messaging platforms (WhatsApp, Telegram, Discord, Slack, Microsoft Teams, iMessage, Matrix, Google Chat, Webex, Linear, GitHub, WeChat, email via Resend) and uses Anthropic's official Agent SDK so every container gets Claude Code's full toolset. Multiple independent community forks appeared in the same week.
