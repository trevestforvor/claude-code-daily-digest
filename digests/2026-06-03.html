Microsoft Drops Claude Code by June 30

Microsoft is canceling Claude Code licenses across its Experiences & Devices division (Windows, Office, Teams, Surface) by June 30, steering engineers toward GitHub Copilot CLI — after per-engineer monthly API costs hit $500–$2,000 and burned through the annual AI budget in months. Uber hit the same ceiling, spending its entire 2026 AI-tools budget on Claude Code and Cursor in just four months. Anthropic launched Opus 4.8 into that exact crisis; both cases are now the go-to reference for token-billing cost ceilings at enterprise scale.

Claude Sonnet 4 & Opus 4 API Deprecation — June 15

The original claude-sonnet-4-20250514 and claude-opus-4-20250514 retire on the Anthropic API in 12 days — June 15 at 9 AM PT. Any app or script calling either pinned version identifier will start throwing errors on that date. Consumer Claude.ai and managed Claude Code are unaffected; API integrations must migrate to claude-sonnet-4-6 and claude-opus-4-8 respectively. MindStudio estimates millions of production API calls are at risk for teams that haven't updated.

Claude Code v2.1.159–161 (June 2026)

Three releases shipped in the past week. Headline additions: plugins in .claude/skills now load automatically without marketplace install; `claude plugin init <name>` scaffolds a new plugin in-place; a new `MessageDisplay` hook lets hooks transform or hide assistant text before it renders; `defaultEnabled: false` in plugin.json allows silent installs that activate only when you enable them; skipLfs skips Git LFS downloads for GitHub-sourced marketplace plugins.
