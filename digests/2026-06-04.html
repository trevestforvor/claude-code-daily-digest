Devin Desktop + ACP (Agent Client Protocol)

On June 2 Cognition retired the Windsurf brand and relaunched the IDE as Devin Desktop with support for the Agent Client Protocol (ACP) — an open JSON-RPC 2.0 standard that lets any compatible agent (Claude Code, Codex, Gemini CLI, OpenCode) run inside any compatible editor. Claude Code v2.1.162 shipped the same day, updating its /ide menu from 'Windsurf' to 'Devin Desktop.' The `agentclientprotocol/claude-agent-acp` adapter wraps the Claude Agent SDK so it speaks ACP natively — meaning Claude Code can now be invoked as a managed subagent from Devin Desktop, JetBrains, VS Code, and Zed without any custom plumbing. ACP was created by Zed in August 2025 and had 25+ agent implementations by June 2026.

Poisoning Claude Code: Supply Chain CVE in GitHub Actions

Published June 1 by GMO Flatt Security researcher RyotaK: a single malicious GitHub Issue could compromise any repository using the official Claude Code GitHub Actions workflow — including Anthropic's own repos. Root cause: `checkWritePermissions` unconditionally trusted any actor ending in `[bot]`, regardless of actual permissions, allowing an attacker with a GitHub App installation token (free, implicit read access to any public repo) to inject code into the action and propagate it downstream. Patched in Claude Code GitHub Actions v1.0.94. If your repo uses any version before v1.0.94, audit immediately. Anthropic issued remediation guidance alongside the disclosure.

secure-claude-code (efij)

Local-first modular security guardrails for Claude Code, MCP tools, and Claude Cowork workflows — structured as YARA-style guard packs that run as PreToolUse/PostToolUse hooks. Five packs ship out of the box: secrets (catches API keys, tokens, .env contents before they leave your machine), exfiltration (blocks unexpected outbound file reads and curl patterns), prompt injection (detects classic injection vectors in user input and tool results), MCP abuse (rate-limits and audits MCP calls across sessions), and risky-agent-actions (flags destructive bash patterns like `rm -rf`, `git push --force`, and `DROP TABLE`). Designed to complement the official Anthropic security-guidance plugin, not replace it — operates at the hook layer without touching the in-session review model.

Security Scanner Plugin (harish-garg)

Claude Code plugin that scans your local codebase for vulnerabilities using GitHub's official Advisory Database — no external API calls, no code leaves your machine. Queries the GitHub Security Advisory API for CVEs matching your installed package versions, cross-references against your lock files (package-lock.json, requirements.txt, Pipfile.lock, Cargo.lock, go.sum), and surfaces findings as actionable in-session tasks. Distinct from the official Anthropic security-guidance plugin (which catches code patterns at write-time) — this plugin focuses on dependency-level CVEs rather than source-code patterns, running a full dependency audit on demand.
