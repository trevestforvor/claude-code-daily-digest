claude-peers-mcp — Ad-Hoc Peer Messaging Between Claude Instances

2.1k stars. Allows every Claude Code session running on your machine to discover the others and send messages ad-hoc — no cloud, no orchestration framework. A local broker daemon (SQLite + HTTP on localhost:7899) handles peer registration; each session's MCP server polls for inbound messages and pushes them into the Claude channel so they appear instantly. Practical use: spin up a planning agent and a coding agent in separate terminals, let them coordinate directly without any hand-rolled API. Already cross-listed on LobeHub, SkillsMP, and mcpmarket — viral pick-up for a small repo.
