WWDC 2026: Claude Lands in Apple Foundation Models — iOS 27, Xcode 27

Apple announced yesterday (WWDC keynote June 8) a new LanguageModel protocol in the Foundation Models framework — a public Swift interface that Claude, Gemini, and OpenAI implement to expose a common inference surface on iOS 27, macOS 27, iPadOS 27, watchOS 27, and visionOS 27. Developers add the Anthropic Swift package, sign in with an API key, and pass typed Swift outputs from Apple's on-device model into a Claude request; swapping to Gemini or back is a one-line SPM change with no session-logic rewrites. Xcode 27 ships a dual-engine agentic coding system — on-device Neural Engine for real-time suggestions, cloud routing to Claude/Gemini/ChatGPT for heavier analysis. Reaches every iOS 27 developer starting this fall.

pdf-mcp (jztan) — Read Multi-Hundred-Page PDFs Without Hitting Context Limits

MCP server that gives Claude Code (and any MCP client) chunked, searchable access to arbitrarily large PDFs — solving the 'context window blows on page 60' failure mode. Three tools: pdf_info (metadata), pdf_search (hybrid BM25 + semantic RRF fusion, OCR via Tesseract for scanned docs), pdf_read_pages (paginated fetch). SQLite cache persists indexes across restarts so the first search is the slow one. 9 releases since January 2026, 7,100+ PyPI downloads. Runs locally — no PDF bytes leave your machine.

Claude Code: Safe Mode, /cd, /reload-skills, Auto-Plugin Loading

Latest Claude Code release batch adds four quality-of-life features that change daily workflow: (1) --safe-mode / CLAUDE_CODE_SAFE_MODE disables all CLAUDE.md, plugins, skills, hooks, and MCP servers — the one-command troubleshoot when a hook is misbehaving; (2) /cd moves the active session to a new directory without breaking the prompt cache mid-session; (3) /reload-skills re-scans skill directories without restarting the agent; (4) plugins in .claude/skills directories load automatically, no marketplace install step needed. Also: disableBundledSkills / CLAUDE_CODE_DISABLE_BUNDLED_SKILLS removes built-in slash commands for minimal installs.
