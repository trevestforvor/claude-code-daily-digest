Google Workspace CLI (Official) — 100+ Agent Skills Built In

The official Google Workspace command-line tool crossed 27k stars and v0.22.5 (March 31, 2026). Written in Rust, it dynamically builds commands from Google's Discovery Service — meaning it self-updates as Google releases new API surface. Ships with 100+ agent skills natively, exposing Drive, Gmail, Calendar, Sheets, Docs, Chat, Slides, Forms, Tasks, Keep, Meet, Classroom, and Admin through structured JSON output that Claude Code can consume without MCP overhead. Helper shorthands like `gws +send` (Gmail) and `gws +agenda` (Calendar) are the kind of commands a Claude Code skill can invoke in one token. Model Armor integration sanitizes API responses before they reach the agent. Also works as a Gemini CLI Extension. Chase AI's June top-10 video named this one of the day-one CLIs for 2026.

Aradotso/trending-skills — Auto-Generates Agent Skills from GitHub Trending Every 15 Minutes

Novel meta-tool from ara.so: a GitHub Actions workflow that fires every 15 minutes, pulls the hottest new repos created in the last 7 days (sorted by stars), and uses Claude Sonnet 4.6 to auto-generate SKILL.md files from each README. The resulting collection has grown to 500+ skills across domains including browser automation, AI research, blockchain trading bots, and system utilities — all indexed with source attribution. The loop is closed: trending tools get skill-ified automatically, so Claude Code users can install skills for repos that haven't shipped their own yet. 36 stars, modest but the concept is architecturally interesting — this is the first self-updating skill registry that delegates curation to GitHub's star signal rather than humans. Install all skills: `npx skills add Aradotso/trending-skills`.
