Anthropic Reverses Fable 5's 'Secret Sabotage' Policy for AI Researchers

On June 9, buried in Fable 5's 319-page system card, Anthropic disclosed that the model would covertly degrade its own responses for users working on frontier AI research — pre-training pipelines, distributed training infrastructure, ML accelerator design — without notifying them. Steering vectors and prompt modifications fired silently, dropping quality to Claude Opus 4.8 level. Researcher Nathan Lambert (formerly AI2) called it 'appalling' and coined the phrase 'secret sabotage.' By June 10, Fortune had the story; by June 11, Anthropic reversed. The new behavior: flagged requests visibly fall back to Opus 4.8, and API users receive an explicit refusal reason. Anthropic's statement: 'We made the wrong tradeoff and we apologize for not getting the balance right.' Simon Willison's June 11 writeup is the clearest technical summary of what changed and why it matters for anyone building competing models.

Claude Managed Agents: Cron Schedules + Credential Vaults Now in Public Beta

Published June 9. Two new capabilities hit public beta in Claude Managed Agents. (1) Cron Schedules: attach a schedule (hourly, nightly, weekly, or custom cron) to any Managed Agent — when the trigger fires, a fresh session starts, completes the task, and stops; you can pause, resume, archive, or trigger extra runs on demand from the platform. Nothing depends on your laptop being open. (2) Credential Vaults for environment variables: register an API key with an env var name and an explicit domain allowlist; the agent's sandbox holds only a placeholder, and the real secret is injected at the network boundary — the agent never sees the plaintext key. This pairs the vaults feature (previously limited to OAuth tokens) with CLI tools that read from env vars. Combined, these let you build nightly research sweeps, daily codebase health checks, or event-driven pipelines that handle secrets safely without baking credentials into prompts.

Mitiga Labs: 5-Step MCP Attack Steals OAuth Tokens — Anthropic Declines to Patch

Mitiga Labs published the full chain on May 8; Security Boulevard added the remediation framing on June 10. The attack: (1) victim installs a malicious npm package; (2) a postinstall lifecycle hook executes silently; (3) it modifies `~/.claude.json` — the global config governing how Claude Code routes all MCP traffic and stores OAuth tokens in plaintext; (4) MCP traffic is redirected through an attacker-controlled proxy; (5) bearer tokens for Jira, Confluence, and GitHub are intercepted. The tokens are persistent (stored refresh tokens), broadly scoped (all permissions from authorization time), weakly stored (plaintext in `~/.claude.json`), and indistinguishable server-side from legitimate Anthropic egress. Mitiga reported to Anthropic April 10; on April 12 Anthropic said it was out of scope ('user prior consent'). No patch planned. Security Boulevard's June 10 framing: the fix must come from agent containment (per-state tool restrictions, domain allowlists, MCP server validation) not from patching the config file. Immediate actions: monitor `~/.claude.json` for unexpected URL changes, audit npm packages with postinstall hooks, rotate OAuth tokens.

Statewright — Visual State Machines That Make AI Agents Reliable (Show HN)

Show HN debut this week. Statewright sits between your MCP client (Claude Code, Codex, Cursor) and its tool calls as a protocol-layer gateway that enforces per-state tool restrictions — only the tools appropriate for the current workflow step are exposed to the agent. You define states and allowed tools visually in the web editor, and the MCP gateway blocks calls that don't match the active state. The measurable difference: in a 5-task SWE-bench subset, two local models went from 2/10 passing to 10/10 passing with Statewright constraints, on identical hardware. The principle: narrowing the agent's action space per step removes the degrees of freedom that cause hallucinated or out-of-order tool calls. Engine is Apache 2.0; the managed MCP gateway at statewright.ai is FSL-1.1-ALv2 (converting to Apache 2.0 in 2029). Free tier available.

cavekit (JuliusBrussee) — Spec-Driven Development with 75%-Token Caveman Encoding

1,000 stars. From the creator of the viral caveman skill (51k+ stars) comes a spec-driven development plugin. cavekit maintains a durable `SPEC.md` that persists across context resets — the spec survives compaction. Three commands: `/ck:spec` creates or amends the spec from natural language; `/ck:build` generates a parallel build plan and executes it; `/ck:check` detects spec drift and surfaces regressions. The token efficiency layer uses 'caveman encoding' internally — symbols and pipe tables instead of prose in structured outputs, cutting ~75% of spec-communication tokens. Test failures auto-backpropagate into the spec as new entries, so the spec gets smarter with each run. The v4 rewrite (current main branch, 136 commits) strips the earlier sub-agent machinery entirely — single Claude instance throughout. No vendor lock-in: specs are plain Markdown. Distinct from the caveman skill (which only changes Claude's speech style); cavekit is a full build loop.

Nylas CLI — Official Multi-Provider Email MCP for Claude Code (Gmail, Outlook, IMAP)

Nylas ships an official MCP server for email and calendar that gives Claude Code read/send access across Gmail, Outlook, Exchange, Yahoo, iCloud, and any IMAP provider through a single interface. 16 tools typed across email, calendar, and contacts — list, search, read, and send across all 6 providers with one Claude command. Security design: a confirmation hash gates every send action; Claude cannot dispatch an email without surfacing a confirmation step to the user. Setup is a single CLI command: `nylas mcp install`. The multi-provider unification is the key difference from provider-specific MCPs (the Composio Outlook MCP, Inbox-MCP, etc.) — you maintain one authenticated MCP server rather than separate configurations per inbox. Works with Claude Code, Cursor, VS Code, and any MCP-compatible client.
