Claude Code Dynamic Workflows + `/deep-research` (Research Preview)

Anthropic's largest architectural addition to Claude Code since parallel agents: dynamic workflows are JavaScript scripts Claude writes on demand, executed by a dedicated runtime while your session stays live. Trigger with the `ultracode` keyword in any prompt, or type `/effort ultracode` to have Claude auto-plan workflows for every task in the session. Bundled command `/deep-research <question>` fans out web searches across angles, cross-checks every source, and returns a cited report with unverified claims filtered out. Scale: up to 16 concurrent agents, 1,000 total per run, all resumable within the session. Plans are visible (and editable) before launch. Save any run as a reusable `/command` for your team. Available on all paid plans, v2.1.154+.

agmsg — Cross-Agent Messaging via SQLite (PH #5, June 9)

#5 Product of the Day on Product Hunt June 9 (219 upvotes, 39 comments), 460 GitHub stars. agmsg is ~500 lines of bash + SQLite that lets Claude Code, Codex, Gemini CLI, and Copilot CLI message each other through one shared local file — no daemon, no network, no framework. Monitor mode (~5s latency) pushes messages in real-time; turn mode checks at the start of each agent turn. Roles and team names are project-scoped; `actas` switches roles mid-session. Unlike built-in subagents (single-vendor, ephemeral) or agent teams (Claude-only), agmsg is persistent and vendor-agnostic — run a Claude Code planner, a Codex implementer, and a Gemini reviewer in three terminals and have them coordinate without a custom orchestration layer.

Claude Code v2.1.176 (June 12) — Hook Path Globs Fixed, /copy in tmux, Session Titles

Released June 12 alongside 174 and 175 (covered in yesterday's digest). v2.1.176's most actionable fix: hook `if` conditions now correctly match path patterns like `Edit(src/**)` and `Read(~/.ssh/**)` — they were silently not evaluating before, meaning hooks that were supposed to fire on specific file paths were firing on everything or nothing. Also fixed: `/copy` and mouse-selection copy in tmux over SSH (a long-standing frustration for remote users), background sessions incorrectly showing 'Working' indefinitely, cloud session authentication timeouts, `/cd` and worktree moves not reporting correct git branch, and Remote Control model switching. New: `footerLinksRegexes` setting lets you add custom regex-matched badge links to the footer, and Bedrock credential caching now respects the actual `Expiration` field instead of a hardcoded 1 hour.

ARIS (Auto-Research-In-Sleep) — Autonomous ML Research via Cross-Model Adversarial Review

11.6k stars. ARIS packages 79 composable Markdown skills that let Claude Code run a full ML research loop while you sleep: idea discovery with GPU pilots, autonomous 4-round adversarial peer review (Claude Code executes; GPT-5.4 or GPT-5.5 acts as independent critical reviewer who rejects weak work), end-to-end paper writing from narrative to LaTeX to PDF, and rebuttal drafting from reviewer feedback. The cross-model adversarial pattern — two models that disagree and debate instead of self-playing — is the structural innovation. Research Wiki persists across runs; failed ideas become anti-repetition data. No framework, no vendor lock-in: the same skills run on Codex, OpenClaw, or any LLM agent.

TrendsMCP — Live Trend Data MCP (Google, YouTube, TikTok, Reddit, and 6 More)

Freshly launched. TrendsMCP connects Claude to real-time trend data across ten platforms: Google Search, YouTube, TikTok, Reddit, Amazon, Wikipedia, news sentiment, App Store, Steam, and npm — all normalized to a 0–100 scale so you can compare velocity across sources in a single query. Practical use cases: SEO research, investment signals, brand tracking, content timing, npm package adoption analysis.
