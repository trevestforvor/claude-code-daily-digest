US Government Orders Anthropic to Suspend Fable 5 and Mythos 5 — Globally

The Commerce Department issued an export control directive to Anthropic on June 12 at 5:21 pm ET citing a 'potential jailbreak' of Fable 5 — a public demonstration by 'Pliny the Liberator' on June 10 that bypassed safety guardrails to extract exploit instructions. The directive barred any foreign national access, which Anthropic says it could not enforce selectively, so it disabled Fable 5 and Mythos 5 for all customers worldwide, routing everyone to Opus 4.8. Anthropic publicly disagrees: 'a narrow potential jailbreak should not be cause for recalling a commercial model deployed to hundreds of millions of people.' Fortune reported that the jailbreak demonstration was performed by a defense cybersecurity firm for authorized red-team purposes, not malicious use.

NVIDIA SkillSpector — Security Scanner for AI Agent Skills (5k Stars, +962 Today)

NVIDIA's open-source answer to the skill-security gap: SkillSpector scans any AI agent skill (Git repo, URL, zip, directory, or single file) for 64 vulnerability patterns across 16 categories including prompt injection, data exfiltration, privilege escalation, supply chain attacks, and MCP-specific risks. Fast static analysis by default; optional LLM semantic pass for intent evaluation. NVIDIA's own research stat: 26.1% of the 71k+ skills in the wild contain vulnerabilities, and 5.2% show likely malicious intent. Risk scores run 0–100 with severity labels; SARIF output supports CI integration.

Kimi K2.7-Code — Open-Source 1T-Param Model That Outscores Opus 4.8 on MCPMark

Moonshot AI released Kimi K2.7-Code on June 11 under Modified MIT (commercial use permitted). It's a 1T-parameter MoE with 32B active parameters per token and a 256K context window. With Fable 5 now suspended globally and Opus 4.8 the fallback, K2.7-Code offers a local alternative that benchmarks above the current default.

JFrog × Anthropic — Enterprise Supply Chain Governance Baked Into Claude Code

Released June 10 as an official Anthropic partner plugin. The JFrog Platform plugin wires Claude Code into JFrog Artifactory and Xray so that when Claude writes or modifies dependency calls, governance runs inline — package security and CVE scoring, license compliance, and provenance validation all fire before the code leaves the editor. The enforcement is policy-as-code: your org's existing JFrog policies gate what Claude can pull. Context: supply chain attacks via AI-generated dependencies are the fastest-growing enterprise risk in the MCP era; this is the first production plugin that closes that loop for teams already on JFrog. Available to all Claude Code users at claude.com/plugins/jfrog.
