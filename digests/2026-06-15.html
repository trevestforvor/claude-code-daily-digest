Claude Code v2.1.172 — Sub-Agents Can Now Spawn Sub-Agents (5 Levels Deep)

For most of 2026, 'subagents cannot spawn other subagents' was a deliberate Claude Code guardrail against infinite recursion. v2.1.172 (June 10) lifted it: sub-agents can now spawn their own sub-agents up to 5 levels deep. The purpose is context isolation, not parallelization — each sub-agent gets a fresh 200K-token window, so a deeply nested workflow offloads its noisy work without polluting the parent's context. Foreground sub-agents can spawn at any depth level; background sub-agents at level 5 cannot go further. Token cost: roughly 7× per branch, so practical use is 2–3 levels. Claude Code lead Boris Cherny framed it as a context management feature for complex workflows. The ruflo project (ruvnet/ruflo) already filed ADR-147 to integrate depth-5 capability into its orchestration layer.

Agent SDK Credit Pools Activated — Day 1 Impact + What Still Runs Free

Credit pools went live at midnight June 15. The GenAI Unplugged workaround guide — published today — documents what still runs on subscription limits: interactive `claude` terminal sessions are untouched; it's only `claude -p`, Agent SDK calls, Claude Code GitHub Actions, and third-party apps that now draw from the $20–$200 credit bucket. The critical detail most developers missed: no automatic fallback when the credit pool empties — workflows simply stop mid-run until next billing cycle or until overflow billing is enabled. The New Stack's coverage puts the effective cost increase at 5–10× for heavy automation users. Zed's documented workaround (confirmed in their blog): route tasks through interactive Claude Code rather than headless calls for non-CI workflows.
