AgentNotch

AgentNotch is a free, MIT-licensed macOS menu-bar app that lives in the system notch and streams a live feed of every Claude Code and OpenAI Codex tool call — what the agent is thinking, which files it reads, which tools it executes — all without leaving your editor. Built by AppGram with zero telemetry; v1.0.0 is available in GitHub Releases. Sparked a wave of notch-ambient agent monitors this week (AgentPeek, Notchi) as multi-session parallel development becomes the new normal.

AgentPeek

AgentPeek ($15 one-time) puts Claude Code and Codex into the Mac notch and menu bar and adds token usage dashboards (5-hour and 7-day rolling totals), live permission-prompt surfacing, and diffs per session. Built natively for Apple Silicon, it wires itself via lightweight hooks on first launch and tracks any session from Ghostty, tmux, iTerm, or VS Code terminal. For teams managing multiple parallel agents, the token-burn visibility alone pays back the cost quickly.

Claude Code /effort ultracode

Typing /effort ultracode in a Claude Code session sends xhigh reasoning effort to the model and triggers automatic Dynamic Workflow orchestration — Claude writes its own JavaScript orchestration script, fans out up to ~199 parallel subagents, cross-checks results, and returns a single coordinated answer. Available on Max, Team, and eligible Enterprise plans; also via the API. Users report it can consume the entire session budget on a single substantive task, so Anthropic recommends scoping carefully before invoking. Extensive week-3 tutorial coverage across Developers Digest, StackNotice, and LaoZhang AI Blog.
