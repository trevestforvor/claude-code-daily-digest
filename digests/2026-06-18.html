Claude Code v2.1.181 — /config Syntax, CLAUDE_CLIENT_PRESENCE_FILE, Bun 1.4

Released June 17 with 20+ changes. Three new quality-of-life additions: (1) `/config key=value` sets any Claude Code setting without leaving the prompt — e.g., `/config thinking=false`, `/config model=claude-opus-4-8`; (2) `CLAUDE_CLIENT_PRESENCE_FILE` env var suppresses mobile push notifications when you're at the machine; (3) `sandbox.allowAppleEvents` opt-in for sandboxed macOS commands that need it. The bundled Bun runtime upgrades to 1.4, auto-retry fires on API connection drops mid-thinking (no more lost reasoning chains), and the subagent panel gets auto-hide, scroll hints, and better organization. Notable fix: Write/Edit no longer produces truncated files on network drives and cloud-synced folders.

Claude Platform Workload Identity Federation GA — No More Static API Keys

Workload Identity Federation (WIF) became generally available on the Claude Platform on June 17. Instead of a shared static API key, each workload authenticates with the identity it already has — an AWS IAM role, GCP or Kubernetes service account, Azure managed identity, GitHub Actions token, or any other OIDC-compliant provider — and the Platform issues a short-lived scoped access token. Every API call is logged against a named service account with its own roles and audit trail. Covers all Claude API endpoints including Claude Code and the Agent SDK. Particularly useful for teams trying to scope Claude Code's automation footprint per environment.

CCPM — GitHub Issues + Git Worktrees for Parallel Agent Execution

8.2k stars. CCPM (Claude Code Project Manager) gives multi-agent development a traceable backbone: ideas become PRDs, PRDs become epics, epics become GitHub Issues, and each issue gets its own git worktree so agents can execute in parallel without conflicts. GitHub Issues are the single source of truth — no hidden agent state. Deterministic bash scripts (zero LLM cost) handle `/standup` and `/status` reporting. The core rule: 'Every line of code must trace back to a specification.' Automaze says it cut their internal shipping time roughly in half after months of internal use. Ships with CLAUDE.md; works with Claude Code, Factory, Cursor, and any Agent Skills–compatible harness.
