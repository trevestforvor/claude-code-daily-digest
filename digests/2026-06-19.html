Claude Design June 2026 — /design-sync, Design System Imports, Bidirectional Claude Code Handoff

Anthropic's June 17 Claude Design overhaul ships three things at once. First, design system import: pull in your approved components from a GitHub repo, design file, or upload — Claude Design then builds against those tokens and checks its own output for brand compliance before showing it to you. Second, /design-sync: a command that syncs both ways — pull the design system into your repo, or push what Claude Code built back into Claude Design for canvas editing. Third, direct canvas WYSIWYG editing inside the Claude sidebar. VentureBeat described this as "a fix for Claude Design's token-burning problem" — the old workflow required constant manual re-syncing that wasted context. Available now on Pro, Max, Team, and Enterprise.

Claude Code Artifacts (Beta) — AI Coding Sessions as Live, Shareable Browser Pages

Launched June 18 in beta for Team and Enterprise. Claude Code Artifacts captures whatever Claude Code just built — a dashboard, a PR walkthrough, an incident checklist, an internal tool — and publishes it as a live, interactive HTML page behind an org-only URL you can paste into Slack. This closes the gap that has existed since Claude Code went GA in May 2025: the agent's output was trapped in a terminal visible only to one person. Private sharing, version history, and multi-source data embedding are all in the beta. No embed codes — it's a URL that resolves to a page.

Claude Code v2.1.183 — Auto Mode Now Hard-Blocks Destructive Git and Infra Commands

Released June 19 (today). Auto mode gains four hard-block rules: (1) `git reset --hard`, `git checkout -- .`, `git clean -fd`, and `git stash drop` are blocked when you didn't ask to discard local work; (2) `git commit --amend` on commits the agent didn't author this session; (3) `terraform destroy`, `pulumi destroy`, and `cdk destroy` unless you specifically requested the stack deletion. Also new: a warning fires when the requested model is deprecated so you see the substitution instead of silently getting a newer model; `attribution.sessionUrl` setting omits the claude.ai link from commits and PRs; and `/config --help` lists all shorthand config keys.

Omnigent (Databricks) — Open-Source Meta-Harness Above Claude Code, Codex, and Pi

Matei Zaharia (Databricks founder) open-sourced Omnigent on June 13 — a meta-harness that sits above Claude Code, Codex, Pi, and custom agents, governing what those agents can do, where they run, and who can watch them work. 4k stars in six days. The built-in Polly orchestrator writes no code itself: it plans, delegates to parallel sub-agents in separate git worktrees, and routes each diff to a reviewer from a different vendor than the writer (e.g. Claude writes, Codex reviews). Enterprise features: approval workflows, spending caps, tool restrictions, and cross-device session sync. Apache 2.0.
