Ralph Wiggum Plugin (Official Anthropic) — Autonomous Loop Until Done

Named after the Simpsons character who embodies persistent iteration despite setbacks, the Ralph Wiggum plugin is an official Anthropic plugin bundled inside the anthropics/claude-code repo. It implements an autonomous loop via a Stop hook that intercepts Claude's exit attempts and re-feeds the same prompt with all prior work still in context, repeating until the task is genuinely complete. Commands: /ralph-loop to start, /cancel-ralph to stop. Unlike /loop or /goal, Ralph runs entirely within a single session with no external bash required. Getting viral attention on r/ClaudeAI this week after a user reported completing a $50k contract for $297 using it overnight. Documentation updated June 2026.

Statewright — Visual State Machine Guardrails for Claude Code via MCP (404 Stars)

'Agents are suggestions, states are laws.' Statewright is a Rust state machine engine that constrains which tools an agent can access in each workflow phase, enforcing the restriction via Claude Code hooks and an MCP plugin. In a 5-phase workflow, the model sees only the 5 relevant tools per phase instead of dozens — eliminating off-path tool calls, premature deployments, and redundant file reads. A visual editor at statewright.ai lets you design workflows graphically and export them. HN Show HN (item 48108778). v1.1.0 released June 1, 2026. Apache 2.0 engine; commercial tiers for hosted orchestration. 404 stars.
