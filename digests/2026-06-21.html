FableWatch — Fable 5 API Monitor That Calls Your Phone the Minute It Returns (Swarm Plan Extracts 400+ Q&As)

FableWatch is an automated return monitor for claude-fable-5 that pings the API every 60 seconds and alerts you via email, text, and automated phone calls the same minute the model comes back online. The Swarm plan goes further: it fires a dedicated VPS with 400+ parallel API calls covering 400+ curated questions to extract maximum knowledge before the window closes again — the resulting dataset is yours to keep. It also connects to GitHub repos to auto-fix PR bugs, resolve open issues, and open fix PRs while the model is online, hands-free. Not affiliated with Anthropic. A small ecosystem of monitoring services has emerged around the ban: isfableback.com and isfable5back.com provide live availability checks; fable5.app/news/ runs a running timeline of ban developments. The existence of these services reflects the community's expectation that Fable 5 will return unpredictably and briefly before full restoration.

agentmemory — 23.6k Stars, 53 MCP Tools, 92% Token Reduction for Persistent AI Coding Agent Memory

23.6k stars. rohitg00's agentmemory is the persistent memory layer most Claude Code users eventually reach for: every session your agent runs gets captured, compressed, and indexed — then injected back as targeted context the next time you open a related project. The three-layer hybrid search (BM25 keyword + semantic vectors + knowledge graph) achieves 95.2% retrieval accuracy on benchmarks and 92% token reduction vs. pasting full conversation history. 53 MCP tools for memory operations, a real-time viewer dashboard at localhost:3113, and 15 skills for in-session querying. Works with Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and Copilot. Apache 2.0, TypeScript. v0.9.27 (June 7, 2026). With Fable 5 suspended and everyone logging longer sessions on Opus 4.8 to compensate, token efficiency tooling like this has become significantly more relevant — a 92% reduction in context token spend translates directly to plan headroom.
