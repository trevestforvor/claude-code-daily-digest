Agentjacking — Fake Sentry Bug Reports Hijack Claude Code, Cursor, and Codex via MCP (2,388 Orgs Exposed, 85% Success Rate)

Tenet Security Threat Labs disclosed 'agentjacking' on June 17: attackers inject crafted error events into a victim's Sentry project using a publicly visible DSN key, the Sentry MCP server surfaces those events to the AI coding agent as real bugs to fix, and the agent executes the attacker's npx command with local privileges. Claude Code, Cursor, and Codex all acted on the injected errors in controlled testing; Tenet logged 100+ confirmed executions across separate organizations in its validation waves. Passive reconnaissance found 2,388 orgs with injectable DSNs — 71 rank in the Tranco top-1 million. Ron Bobrov's team reported 85% success rate. Payload typically exfiltrates AWS credentials, npm tokens, Docker credentials, git credentials, and private repo URLs. The fix: rotate your Sentry DSN and pin MCP data sources to a trusted allowlist.

Canopy — Native macOS SwiftUI App for Parallel Claude Code Sessions with Git Worktrees and Container Sandboxing

Canopy is a native SwiftUI macOS app — no Electron, signed and notarized — that puts parallel Claude Code sessions into a first-class tab interface (Cmd+1-9 to switch). Each session runs in its own git worktree so parallel agents never touch the same files. Sessions can run in sandboxed containers (Docker or Apple Container framework), giving each agent a restricted runtime. One-click 'Merge & Finish' handles the merge-and-cleanup dance when a task is done. Activity dashboard shows where tokens actually went. Julien Simon built it after months of manually managing parallel worktrees. AGPL-3.0, free to download.
