Claude Code v2.1.186 — CLI MCP Login/Logout for SSH, Auto-Respond to Bash Output On by Default, Skills Tab in /plugin

v2.1.186 shipped June 22 with 33 changes. The headliner is `claude mcp login <name>` and `claude mcp logout <name>`: you can now authenticate OAuth MCP servers directly from the CLI without opening the interactive /mcp menu — `--no-browser` redirects the flow through stdin for headless SSH setups. A second behavioral change: bash commands now auto-trigger Claude to respond to their output (`respondToBashCommands: true` is the new default; set false in settings.json to restore old context-only behavior). The /plugin Installed tab gains a dedicated Skills section. The /workflows agent detail view adds status filtering (press f). Bug fixes: JetBrains terminal flickering, Kitty keyboard Shift+non-ASCII drops, Windows PowerShell hanging, macOS orphaned processes at 100% CPU after daemon death.

Simon Willison: Claude Code Ports Moebius 0.2B Image Inpainting from PyTorch/CUDA to In-Browser WebGPU Overnight

Simon Willison published a detailed write-up yesterday (June 22) of using Claude Code to port the Moebius 0.22B image inpainting model — originally PyTorch + NVIDIA CUDA — to run entirely in the browser via ONNX Runtime Web on the WebGPU backend. Claude suggested the ONNX Runtime Web approach (one layer below Transformers.js) and then autonomously drove the conversion: graph topology translation, tensor shape alignment, and browser-side weight loading. The result is a live demo at simonw.github.io/moebius-web/ — 1.27 GB of model weights download on first run and cache in the browser's Cache Storage for reuse. The post is a good data point for Claude Code's ability to handle cross-framework ML porting with minimal human guidance.

Claude Managed Agents: Self-Hosted Sandboxes (Public Beta) and MCP Tunnels for Private Networks (Research Preview)

Announced at Code with Claude Tokyo (June 10–11) and now in docs: Claude Managed Agents ships two new capabilities. Self-hosted sandboxes (public beta) let you configure exactly where tool execution runs — partner providers include Cloudflare, Daytona, Modal, and Vercel — so agents can write and run code in your own infrastructure rather than Anthropic's default sandbox. MCP tunnels (research preview) let agents connect to MCP servers inside private networks without exposing them publicly: you run a lightweight tunnel client inside your VPN or private cloud, and the agent reaches it through the encrypted tunnel. Together these address the two biggest enterprise blockers for agentic Claude Code: data-residency and internal tooling access.
