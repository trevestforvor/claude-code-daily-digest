Claude Code v2.1.191 — /rewind Before /clear, 37% CPU Drop During Streaming, MCP OAuth Retry

v2.1.191 released June 24. The headline feature is `/rewind`: you can now resume a conversation from the turn just before you ran `/clear`, recovering context you thought was gone. Network UX fix: hosts you allow once with 'Yes' in the sandbox permission dialog are now remembered for the full session instead of re-prompting on every connection. Performance: streaming CPU usage down ~37% via 100ms text-update coalescing and a fix for long-session terminal output cache growth. MCP improvements: transient network error retry on capability discovery, and OAuth retry with headless-environment handling for CI/CD. Bug kills: scroll-position jump while reading mid-stream, background agents resurrecting after stop, and hooks with comma-separated matchers silently never firing.

CARL — Context Augmentation & Reinforcement Layer: Keyword-Matched Domain Rules Replace Static CLAUDE.md (~50% Token Savings)

ChristopherKahler/carl (351 stars) replaces your static CLAUDE.md with a domain-based, keyword-triggered rules system: say 'YouTube script' and only your writing rules load; start debugging and only your dev-standards rules load — nothing extra. Rules are stored in ~/.carl/ as JSON domains with per-entry keyword triggers; a companion MCP server handles the just-in-time injection. Charlie Automates, who co-ships Chris AI Systems products, says this cuts ~50% of context token spend on typical sessions because Claude never loads behavioral rules irrelevant to the current task. Global rules still load every time; project-level domains override global ones. Free, MIT.

PAUL — Plan-Apply-Unify Loop: Structured Claude Code Development with 1,012 Stars; Charlie Automates' 'The Meta Nobody's Talking About'

ChristopherKahler/paul (1,012 stars) enforces a three-phase loop that prevents the most common Claude Code failure mode — orphan plans that nobody reconciles. Every session: Plan (structured design before code), Apply (build against the plan), Unify (close the loop — reconcile plan vs what actually happened, update state, log decisions). The UNIFY phase is non-skippable by design. Charlie Automates' blog post 'SEED + PAUL = The Claude Code Meta Nobody's Talking About' describes this as the stack Charles and Chris have used on every project they've shipped in the past few months. Works for software, marketing campaigns, and automation workflows. Pairs with SEED (project incubator, 270 stars) and CARL (dynamic rules) for a complete Claude Code operating layer.
