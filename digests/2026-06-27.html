MCP OAuth Token Hijack (Mitiga Labs)

Mitiga Labs documented a 5-step MITM chain: a malicious npm postinstall hook silently edits ~/.claude.json to redirect all MCP traffic through attacker infrastructure, harvesting plaintext OAuth bearer tokens (persistent, broadly scoped, unattributable server-side). Reported to Anthropic April 10; Anthropic declined to patch, citing user consent as a prerequisite. Security Boulevard and SecurityWeek picked it up in June.
