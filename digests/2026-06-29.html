context-mode — 18.3k Stars; Sandboxes Tool Output 98% (315 KB → 5.4 KB) via MCP + Hooks

context-mode is an MCP plugin that intercepts Claude Code's tool results before they enter the context window, writes raw output to disk, and hands Claude a condensed summary — shrinking 315 KB to 5.4 KB (98% reduction). Session continuity is maintained by logging every file edit, git operation, task, and error in SQLite so the model resumes exactly after compaction. A 'Think in Code' pattern discourages repetitive file reads in favor of agent-written analysis scripts. 18,300 stars, 2,054 commits.

CCPM (automazeio/ccpm) — 8.2k Stars; GitHub Issues + Git Worktrees for Up to 12 Parallel Claude Code Agents

CCPM turns GitHub Issues into an agent task database and Git worktrees into isolated per-agent workspaces — up to 12 Claude Code agents running simultaneously, each on its own branch, with zero merge conflicts. PRDs decompose into issues; tasks marked `parallel: true` run concurrently; progress shows up in issue comments so humans see live AI work without tailing logs. Context persists in project files across sessions, not in chat history. Compatible with Claude Code, Factory, Amp, OpenCode, Codex, and Cursor via the agentskills.io standard. 8,200 stars.
