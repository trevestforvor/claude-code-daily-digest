ponytail (DietrichGebert) — 73.7K Stars; 7-Rung Decision Ladder That Cuts Code Output 54% and Tokens 22%

Launched June 12, ponytail hit 44K stars in 9 days and is now at 73.7K — the fastest-growing Claude Code plugin of June 2026. It injects a mandatory 7-rung minimalism ladder before Claude writes any code: Does it need to exist? Already in codebase? In stdlib? Native platform feature? Existing dependency? One-liner? Only then: minimum code. Benchmarks on a real FastAPI + React repo across 12 tasks show 54% fewer lines, 22% fewer tokens, 20% lower cost, 27% faster completion, 100% safety maintained. At the extreme end, an over-built date picker shrank 94%. v4.8.4 (June 29) added Hermes support. Works with Claude Code, Codex, GitHub Copilot CLI, OpenCode, and Gemini CLI. At least 6 YouTube reviews in the past 2 weeks, including a Caveman vs. Headroom vs. Ponytail comparison.

headroom v0.30.0 — 56.4K Stars; 60-95% Token Reduction via Smart Compression Layer (Released July 3)

v0.30.0 shipped July 3 (yesterday) — headroom's 160th release. It compresses tool outputs, logs, files, and RAG chunks 60-95% before they reach the LLM, using three purpose-built engines: SmartCrusher (JSON), CodeCompressor (AST-aware), and Kompress-v2-base (general text). Compression is reversible — originals are cached locally for on-demand retrieval. Three deployment modes: Python library, transparent proxy (headroom wrap claude), or MCP server. v0.30.0 also adds cross-agent memory dedup so Claude Code, Cursor, and Codex share compressed context without re-processing the same files. LiteLLM integrated headroom natively in June. At 56.4K stars, it's one of the top 5 starred Claude Code tools and is new to this digest.

PMB (oleksiijko) — Local-First Persistent Project Memory MCP; 290 Stars, v1.2.2 June 30

PMB (project memory base) solves the cold-start problem: every new Claude Code session wastes minutes re-explaining decisions already made, directions tried, and why the architecture looks the way it does. v1.2.2 stores them in a local SQLite database with hybrid three-layer retrieval — BM25 keyword + vector semantic + entity graph — with ~35ms warm recall. No cloud, no API key on the read path. Connects via `pmb connect claude-code` which writes the MCP config automatically; also works with Cursor, Codex, Windsurf, and Zed. Appeared on HN 'Show HN: Recall – Local project memory for Claude Code' about a week ago.
