Graphify — 74.8K Stars; /graphify Turns Any Codebase Into a Queryable Knowledge Graph (71.5x Token Savings)

YC S26 company Graphify has reached 74.8K stars with a skill that parses your entire codebase (code, SQL schemas, R scripts, shell scripts, docs, PDFs, images, videos) into a local queryable knowledge graph — then Claude queries the graph instead of re-reading files. Code is parsed locally via tree-sitter (no API calls); docs and media route through the session model.
