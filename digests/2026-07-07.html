Claude Code v2.1.202 — Dynamic Workflow Size Setting; Fixed Duplicate Skill Loading; /review Reverted to Single-Pass

v2.1.202 shipped July 6 with one headline feature and one critical fix: The /config now has a 'Dynamic workflow size' toggle (small/medium/large) that advises how many agents to spawn per workflow — useful for keeping costs predictable on Max plans. The critical fix: re-invoking an already-loaded skill no longer appended a full duplicate copy of its instructions every time — a context-bleeding bug that inflated token costs on any session that called a skill more than once. Also: /review <pr#> is now back to a fast single-pass review (the multi-agent version moved to /code-review <level> <pr#>); workflow.run_id and workflow.name OTel attributes enable per-run cost tracing; fixed background sessions dropping on sleep/wake; fixed Remote Control commands failing; improved /workflows agent list with wider titles and dedicated time column.
