SkillCloak — HKUST Researchers Show Malicious Claude Code Skills Can Evade Static Scanners at 90%+ Rate

Hong Kong University of Science and Technology researchers published 'Cloak and Detonate: Scanner Evasion and Dynamic Detection of Agent Skill Malware' (July 6) introducing SkillCloak — a self-extracting packing technique that rewrites suspicious tokens, credential paths, and URLs into semantically equivalent forms the agent quietly reassembles at runtime, evading static skill scanners at 90%+ rates. Demonstrated payloads steal credentials, exfiltrate source code, and install backdoors while appearing benign to the same scanners tools like AgentShield and ECC run. Runtime behavior auditing is far more resilient than static analysis. Covered by The Hacker News, Help Net Security, and GB Hackers. Key takeaway: don't install skills from untrusted sources even if they pass a scanner.
