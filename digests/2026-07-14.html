jrenaldi79/sidecar — Parallel AI Window for Claude Code; Fork to Gemini/GPT/DeepSeek via OpenRouter; Fold Results Back

A CLI companion that reads your live Claude Code session from ~/.claude/projects/[project]/[session].jsonl and routes it in parallel to any OpenRouter-supported model (Gemini, GPT-4o, DeepSeek, etc.). Three modes: Chat (fact-check + human review), Plan (strict read-only, no writes), Build (full autonomy). Hit Cmd+Shift+F to FOLD — generates a structured diff summary you can approve and apply back to the main session. Surfaces systematic blind spots: if Claude missed an edge case that Gemini catches, you see it. MCP server auto-registered for Claude Desktop and Cowork.
