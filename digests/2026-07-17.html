Claude Code v2.1.212 — /fork → Background Sessions; /subtask New; MCP Auto-Background at 2 Min; WebSearch Cap

Released today (July 17). Five headline changes: (1) /fork now copies your conversation into a new background session visible in `claude agents` while you keep working — the old in-session subagent is renamed /subtask; (2) /resume now lets you pick and resume any past session as a background agent; (3) MCP tool calls running longer than 2 minutes automatically move to background, preventing UI lockups; (4) WebSearch is capped at 200 calls/session (tunable) to stop runaway research loops; (5) subagent spawns capped at 200/session with /clear resetting the budget. Also: prompt caching now works behind Bedrock and Vertex gateways, reduced inter-agent token usage, and a worktree symlink security fix.
