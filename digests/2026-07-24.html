Anthropic Claude Security Plugin — Official Beta; Multi-Agent Vulnerability Scanner; /claude-security in Claude Code

Anthropic shipped the official Claude Security plugin in beta on July 22-24, 2026, bringing AI-powered vulnerability scanning directly into Claude Code. louislva/claude-peers-mcp — Let All Your Claude Code Sessions Talk to Each Other in Real Time; SQLite Local Broker

An MCP server that lets every Claude Code instance running on the same machine discover all other instances and exchange messages in real time. A lightweight local broker daemon (SQLite + HTTP, localhost:7899) handles registration and message routing; each session's MCP server pushes inbound messages directly into the Claude context window so they arrive instantly without polling. Practical use: your frontend Claude Code session can ping your backend session to ask what the new endpoint's JSON response shape is, get the answer in-context, and continue — no context-switch, no copy-paste. Covered on HN Show HN; also in the aradotso/trending-skills auto-generated index. April 2026 initial release.
