Claude Code v2.1.219 (July 24) — DirectoryAdded Hook; sandbox.network.strictAllowlist; Depth-3 Subagents

Beyond landing Claude Opus 5 as the default, v2.1.219 ships three notable engineering additions. `DirectoryAdded` hook fires whenever `/add-dir` or the SDK `register_repo_root` registers a new working directory mid-session — lets hooks react to scope changes in large monorepo workflows. `sandbox.network.strictAllowlist` denies all non-allowlisted hosts for sandboxed commands without prompting, giving teams a hard network-egress control. And nested subagents can now spawn their own subagents up to depth 3 (was 1), enabling three-tier orchestration trees without manual forwarding. Also adds `workflowSizeGuideline` as a settable key.
