MCP 2026-07-28 Spec — Stateless Core; MCP Tunnels; 3 New Extensions; 400M Monthly Downloads

The biggest MCP protocol update since launch shipped July 28, 2026: the protocol drops its stateful session model for a stateless HTTP core — no initialization handshake, no Mcp-Session-Id, every request self-describing via _meta headers and routable via standard load balancers.
