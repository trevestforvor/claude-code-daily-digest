MCP 2026-07-28 Spec — Stateless Core; No Sessions; Header Routing; Claude Support Rolling Out

The fifth MCP release (finalized July 28) drops sessions and initialize entirely — the protocol core is now pure request/response, enabling serverless and edge deployment with parallel handshakes. New in this spec: header-based routing for multi-tenant servers, cacheable list results (list once, reuse until invalidated), hardened OAuth, and a formal extensions framework for Multi Round-Trip Requests and interactive UIs. GitHub's MCP Server shipped compatibility July 23. Anthropic announced the Claude rollout on the same day the spec landed; a migration guide for session-stateful servers is linked in the MCP blog.
