Claude Code Auto Mode Default — Live Today; AI Safety Beats Human Review

Auto mode went live today (August 14) as the default permission mode for all new Pro, Max, and Team sessions. Instead of prompting you at every step, a classifier blocks any action deemed irreversible, destructive, or outside your environment — and when blocked, Claude usually finds a safer path or asks. Internal tests with 1,053 paid users found auto mode caught 89% of dangerous commands vs 13.6% for human review (humans approve 97% of prompts reflexively). Trajectory Labs ran 720 prompt injection attacks; auto mode blocked all 720. Config: Shift+Tab cycles modes mid-session; set defaultMode or disableAutoMode in managed settings. Enterprise and API follow in September.
