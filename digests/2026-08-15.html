Claude Code v2.1.232–233 — Subagent Forking Default, @-mentions, GitLab MR Support

Two releases landed August 13–14. v2.1.232 turns subagent forking on by default — a `subagent_type: "fork"` agent now inherits the full conversation and prompt cache with no extra setup — and adds @-mention syntax: type `@` in any prompt to name another live Claude session and send it a message directly via SendMessage. v2.1.233 ships GitLab merge request support in `--worktree` and `claude agents` view (MRs render as `!N`), a Linux memory cgroup guard for runaway builds (`CLAUDE_CODE_TOOL_MEMORY_LIMIT`), and removes the built-in todo/task-tracking tools from Opus 4.8+, Sonnet 5, Fable 5, and Mythos 5 — restore them with `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`.

Claude Code Auto Mode Default — Day 4; Now Live for All Pro/Max/Team Plans

Auto mode went live August 14 as the default permission mode for all Pro, Max, and Team sessions. A classifier blocks any action deemed irreversible, destructive, or outside your environment — when blocked, Claude usually finds a safer path or asks. Internal tests with 1,053 paid users found auto mode caught 89% of dangerous commands vs 13.6% for human review (humans approve 97% of prompts reflexively). Trajectory Labs ran 720 prompt injection attacks; auto mode blocked all 720. Config: Shift+Tab cycles modes mid-session; set defaultMode or disableAutoMode in managed settings. Enterprise and API follow in September.
