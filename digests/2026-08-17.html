Anthropic Invisible Text Watermarks — EU AI Act Compliance, Applied Globally to All Claude Products

Starting August 2, 2026, every new Claude model — including Claude Code — embeds an invisible statistical watermark in every text response it generates. Anthropic uses the SynthID-Text technique (from Google DeepMind): the model subtly biases word-choice randomness at low-stakes decision points, leaving a pattern undetectable to readers but recoverable with a detection key. Marks survive copy-paste and light edits; they fade under heavy rewriting. The announcement (Aug 11) was followed by a detailed technical blog post (Aug 15). A public detection API is coming. Global rollout — not EU-only — covers Claude.ai, Claude Code CLI, Claude Desktop, Claude Cowork, Claude Tag, and API. Older models get watermarking phased in by December 2026.
