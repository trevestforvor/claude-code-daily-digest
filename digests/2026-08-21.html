Claude Code v2.1.237 — Built-In Concise Output Style Skips Preamble, Stays Thorough

v2.1.237 (August 20) ships a built-in Concise output style selectable in `/config → Output style`. It cuts the preamble, narration, and filler sentences Claude typically leads with while keeping full technical depth — responses jump straight to the result. Distinct from existing custom styles: it requires no SKILL.md and isn't token-compressed (no caveman tradeoff), just purpose-driven prose. Pairs naturally with auto mode for a session that feels much more tool-like.

Claude Code v2.1.236–238 — keybindingFlavor Readline, headersHelper, macOS Sandbox, Memory Leak Patched
