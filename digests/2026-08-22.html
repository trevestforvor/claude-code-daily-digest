RTK (Rust Token Killer)

Single zero-dependency Rust binary that transparently wraps 100+ dev commands (git, cargo, npm, docker, ls, cat) and compresses their stdout before it reaches the LLM context window. Real sessions drop from ~150K to ~45K tokens per 30 minutes. A PreToolUse hook auto-rewrites commands so no workflow changes are needed. Apache 2.0, 77k stars, updated today.
