Claude Code v2.1.243 — Released Today; modelPicker, 1-Hour Cache Tuning, 340 MB → 75 MB Binary, 40–70 MB Less Memory

Released August 25: the biggest single Claude Code drop in weeks. Boris Cherny at YC Startup School — Anthropic Deleted 80% of Claude Code's System Prompt. The Model Got Smarter.

Published fresh off Opus 5's launch, Claude Code creator Boris Cherny told YC Startup School that Anthropic stripped more than 80% of Claude Code's system prompt when Opus 5 arrived — and the model performed better without the scaffolding, not worse. Cherny's argument: the entire AI dev-tools industry is building products for yesterday's weaker models. Frontier models today can handle harder tasks with fewer instructions, and over-prompting is actively handicapping them. The talk also covers why Cherny hasn't written a line of code in months, how Opus 5 hit 30% on ARC-AGI, and why cost-per-task comparisons are the wrong frame.
