Claude Fable 5.1 — 75% Cache Read Cost Drop, Same Headline Price

Anthropic shipped Fable 5.1 and Mythos 5.1 on September 1. The headline rate ($10/$50 per million tokens) stays identical to Fable 5, but cache reads collapse from $1.00 to $0.25 per million tokens — a 75% cut — putting typical workload costs 25% lower and highly-agentic workflows (where cached context dominates) 45% lower. Both models match or beat Fable 5 on Terminal-Bench 4.0 and Humanity's Last Exam with 1M context and 128K output. Mythos 5.1 is the same architecture with looser safeguards, restricted to vetted cybersecurity and life-sciences orgs via trusted-access programs.

Claude Code Self-Hosted Environments — Public Beta for Team & Enterprise

Announced August 6 and now in public beta: Claude Code sessions can run on compute your team controls instead of Anthropic-hosted cloud. Sessions start from web, mobile, desktop, or a routine, but execute inside your network — next to your internal services, toolchains, and compliance controls. Repository checkouts, build artifacts, secrets, and session-created files never leave machines the org provisions. Available for Team and Enterprise plans; off by default; not available for ZDR organizations.

Statewright — Visual State Machines That Make AI Agents Reliable

490 GitHub stars, 120+ HN upvotes on Show HN. Statewright is a Rust-powered state machine engine that constrains which tools a Claude Code agent can touch in each workflow phase — planning, implementation, testing, deploy. The agent sees 5 tools instead of dozens; the engine (not a model) enforces transitions. On a 5-task SWE-bench subset, two local models went from 2/10 to 10/10 passing under Statewright constraints. Core engine is open-source; managed cloud service at statewright.ai. "Agents are suggestions, states are laws."
