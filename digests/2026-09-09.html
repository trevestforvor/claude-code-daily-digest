Claude Code /skill-doctor — Find Which Skills Are Eating Your Context (2.1.261)

Added in 2.1.261 (September 4). `/skill-doctor` shows which loaded skills a session never invoked and exactly how many tokens each one costs per turn — so you can prune the dead weight. Interactive mode opens the report in the Plugin Manager's Stats tab; headless `-p` prints plain text. Context: Anthropic already removed 80%+ of Claude Code's own system prompt with no measurable eval drop. Now you can apply the same discipline to your installed skills.

context-mode — 21.6K Stars; 98% Tool Output Reduction via MCP Sandbox + Session Memory

21,600 stars — on GitHub's trending recap for September 6. Sandboxes all tool output so raw data never enters the context window: 315 KB of tool output becomes 5.4 KB (98% reduction). Every file edit, git operation, task, error, and decision is tracked in SQLite; on compaction, the session is indexed via FTS5 and only relevant events are retrieved using BM25 search. Ships 11 MCP tools plus full lifecycle hooks (PreToolUse, PostToolUse, UserPromptSubmit, PreCompact, SessionStart, Stop). Supports 17 platforms including Claude Code, VS Code Copilot, JetBrains Copilot, and Cursor.
