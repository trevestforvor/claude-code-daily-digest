Ralph Wiggum Plugin — Official Anthropic Infinite-Loop Plugin, Going Viral

Official plugin inside anthropics/claude-code (145K stars) that creates a persistent AI loop without babysitting: a Stop hook intercepts Claude's exit, feeds the same prompt back, and repeats until a configurable completion-promise string appears. Invented by Geoffrey Huntley ('he just keeps going'), now packaged by Anthropic. Command: `/ralph-loop "Build a REST API" --max-iterations 50 --completion-promise COMPLETE`. Multiple YouTube videos going viral this week. Reddit thread debating it vs the built-in `/loop` — main difference: Ralph runs inside the current session preserving file state across iterations, `/loop` starts fresh each time.

SEED + PAUL — Claude Code's Plan-First Meta Workflow (Charlie Automates)

PAUL (1.2K stars) is a Plan-Apply-Unify Loop for Claude Code: every task closes with a mandatory UNIFY step that reconciles what was planned vs. what was built, logs decisions, and updates state — designed to prevent the context-rot that degrades quality as sessions grow. SEED (281 stars) is a companion project-incubator: type-aware guided exploration from raw idea to a structured PLANNING.md, then a one-command `/seed launch` hands the plan to PAUL via `paul.toml` frontmatter. Charlie Automates called this combo the 'Claude Code Meta nobody's talking about' in their most recent video. Both are free, MIT-licensed, zero-dependency markdown skills.
