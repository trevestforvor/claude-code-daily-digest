Spotify Portal / Shunt

Spotify's open-source Claude Code plugin intercepts every Read call via a PreToolUse hook: files over 350 lines are blocked and handed to a cheaper worker model through the Portal CLI actions registry instead of Opus. Result: 90% token reduction measured across a Java monorepo (mean bulk-read savings, not a theoretical estimate). Apache-2.0, 1.5k stars. The pattern generalises to any agent.

Ralph Wiggum (Official Plugin)

Official Anthropic plugin (v1.0.0, by Daisy Hollman) that implements autonomous task loops via a Stop hook: run `/ralph-loop` with a task description and Claude keeps re-entering the same prompt each time it tries to exit, iterating until a completion condition is met. Named after the Simpson's kid who tries again regardless. Useful for overnight batch tasks and long-running codegen.
