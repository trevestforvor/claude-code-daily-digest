Draws every pull request as an animated architecture and data-flow walkthrough posted inside the PR itself — one dot crossing one arrow at a time in execution order. Runs as a GitHub App, GitHub Action, GitLab CI component, Bitbucket pipe, CLI, or a Claude Code skill. Differentiates from Claude Code Review by showing what the whole change is rather than which line is wrong. 1.7k stars.
