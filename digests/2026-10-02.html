Claude Code v2.1.287

October 1 release ships Claude Mods — a new extension point letting plugins modify Claude's deeper behavior at runtime (not just slash commands and hooks). MCP improvements add URL-prompt support for OAuth sign-in flows, and Remote Control gains a built-in `gh api` (REST) for Anthropic-managed git sessions.

Graphify

Type `/graphify .` in Claude Code and it transforms your entire codebase — plus docs, SQL schemas, configs, and PDFs — into a queryable knowledge graph in seconds. Local deterministic AST parsing via tree-sitter (37 languages, no LLM call) handles code; semantic analysis handles docs. Outputs graph.html (interactive click-through visualization), GRAPH_REPORT.md (key concepts and surprising connections), and graph.json (queryable data). An MCP server mode makes it work for repeated programmatic access. Community detection uses the Leiden algorithm; edges are tagged EXTRACTED vs INFERRED. 123k stars.
