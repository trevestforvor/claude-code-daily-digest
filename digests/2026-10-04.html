Graphify

Type `/graphify .` in Claude Code and it transforms your entire codebase — plus docs, SQL schemas, configs, and PDFs — into a queryable knowledge graph in seconds. Local deterministic AST parsing via tree-sitter (37 languages, no LLM call) handles code; semantic analysis handles docs. Outputs graph.html (interactive click-through visualization), GRAPH_REPORT.md (key concepts and surprising connections), and graph.json (queryable data). An MCP server mode enables repeated programmatic access. Community detection uses the Leiden algorithm. 123.4k stars.
