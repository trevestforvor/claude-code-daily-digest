PhotoCraft

23.8k stars — a clean-room reimplementation of Adobe Photoshop in pure Rust (MIT/Apache-2.0). Every operation goes through a single registry of 500+ commands accessible via the UI, CLI, JSON control channel, and MCP server. Run `photocraft-cli mcp` and any agent (including Claude Code) can drive it as a tool — open PSD, select layer, apply adjustment, export. Handles layers, masks, vectors, type, and real PSD round-trips. AGENTS.md ships in the repo. Early alpha but trending continuously Oct 5–7.

Vibe-Wise

3.1k stars — Claude Code plugin that makes the agent teach you while it builds. Three checkpoints: Build (reason through the problem together), Design (confirm a plan before a single line of code is written), and Implementation (authorize each write with an explanation of what changed and why). Preferences, learning notes, and a project map persist in `.vibe-wise/`. Trending on GitHub Oct 5 and growing to 3.1k. The thesis: vibe coding shouldn't turn you into a clipboard.

OX Security: 15,465 Public MCP Servers Audited

OX Security audited 15,465 indexed public MCP servers (reported Oct 6) and found zero marketplace-level vetting — expired domains, consumer-tunnel-hosted endpoints, and no access controls as the norm. Separately, GBHackers reported an active MCP OAuth traffic exploit enabling session credential hijacking the same week. Given that Claude Code runs MCP servers at the full permission level of the user's shell session, this is the supply-chain risk report the ecosystem has needed.
