Claude Code v2.1.304 — Mods Get Human Gating + Code Review Levels in UI

Official Anthropic (Oct 19): v2.1.304 adds `decider: "person"` and `isReadOnly` to the mod `tool.check` API — a mod can now flag specific tool calls for human approval rather than auto-block or auto-allow. Companion change: Code Review's Quick / Standard / Deep levels are now selectable directly in the UI (previously API-only). Also adds `/claude-api managed-agents-secure` as a new security audit command and expands `/auto-mode-setup` to Bedrock, Vertex, and Foundry.
