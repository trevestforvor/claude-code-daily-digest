REA — Reverse Engineer Anything

REA is an open-source MCP server that gives Claude Code (and Codex, Cursor, Gemini CLI) disassembly and decompilation tools for binaries, JavaScript/Electron apps, APKs, .NET assemblies, and firmware — all running locally. Created in April 2026, it now sits at 355k GitHub stars with secondary-source coverage in Italian, Vietnamese, Korean, and Portuguese tech blogs. Install is a single command and routes analysis to whichever of Hopper, Ghidra, or IDA you already have.

planning-with-files

A persistent, file-based planning skill (27.6k stars, last updated Oct 20) that keeps task_plan.md, findings.md, and progress.md on disk so the plan survives /clear, compaction, and crashes. Hooks re-inject the active plan at the start of every turn, and SHA-256 hashes detect tampering. The /plan-doctor self-check validates resolution, injection, attestation, and hook latency. Works with Claude Code, Cursor, Codex, Copilot, Gemini CLI, Kiro, and 60+ other agents.

Houtini LM

An MCP server (121 stars, Oct 10) that lets Claude delegate bounded subtasks — file reviews, code drafts, embeddings — to a local or cheap cloud LLM. File contents go straight from disk to the other model and never enter Claude's context window; Claude only sends a short tool call and reads a summary back. The author's benchmark on four TypeScript review tasks reported 86–95% token savings (avg 93.3%). Supports LM Studio, Ollama, OpenRouter, DeepSeek, and others.
