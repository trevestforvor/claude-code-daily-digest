RTK — Bash Output Filter for LLM Token Savings

CLI proxy (84.4k stars) that intercepts shell commands and compresses their output before a coding agent reads it: filters noise, groups similar items, truncates redundant context, and collapses repeated log lines. The project claims 60–90% token reduction on common dev commands — `git log` keeps only hash/author/subject; `cargo test` shows only failures. Works via Claude Code's Bash hook. Note: built-in tools (Read, Grep, Glob) aren't affected.
