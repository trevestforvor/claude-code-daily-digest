Agent Skills → Agentic AI Foundation

On October 22, Anthropic donated the Agent Skills standard — name, logo, GitHub org, and agentskills.io domain — to the Agentic AI Foundation under the Linux Foundation. The spec now has 280 million installs across 70+ platforms (ChatGPT, Cursor, GitHub Copilot, VS Code). Skills you write for Claude Code remain compatible everywhere; the standard is now vendor-neutral with David Soria Parra and Mahesh Murag as lead maintainers.

Claude Code Mods

Launched October 1 in v2.1.287, Mods are TypeScript/JavaScript functions that hook into Claude Code events (tool calls, sent prompts, UI draw) — letting a plugin rewrite a prompt, add a pane, or replace a built-in feature. Anthropic already ships four mods: `diff`, `agents-md`, `sec-default`, and `telemetry`. Install community mods through `/plugin` like any other plugin; inspect source first since mods run with full machine access.
