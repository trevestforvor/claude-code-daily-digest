agent-desktop

Vercel Labs launched agent-desktop (8.8k stars, 2.2k stars today Nov 2) — a Rust CLI that gives AI agents computer use by reading the OS accessibility tree rather than guessing from pixels. It returns JSON snapshots of every UI element with stable 'ref' IDs, lets agents act on them, and errors loudly on stale refs so agents re-snapshot instead of guessing.
