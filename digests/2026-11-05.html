Headroom

78.9k stars, updated Nov 5. Compresses tool outputs, logs, files, and RAG chunks before they reach the LLM — measured 21–57% fewer input tokens on real agent scenarios (SRE incident debugging 57%, codebase exploration 42%, GitHub issue triage 30%), with 90%+ on JSON logs and repeated lines. Uses AST-aware code compression, a HuggingFace prose model (Kompress-v2-base), and a CacheAligner that avoids breaking provider KV-cache prefixes. Reversible: originals cached locally. Apache-2.0.
