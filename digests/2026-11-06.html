Opus 4.8 Fast Mode: 25 days to migrate

Announced in v2.1.316 (Oct 31): Opus 4.8 fast mode is removed November 30, 2026. After that date, fast-mode requests on Opus 4.8 return an error instead of succeeding. Migration path is Opus 5.5 fast mode — which is also cheaper ($8/$40 per MTok input/output vs $10/$50 for 4.8). Change the model via `/model` in-session or update `model` in `~/.claude/settings.json`. Check any CI/CD pipelines that hardcode `claude-opus-4-8` with `speed: "fast"`.
