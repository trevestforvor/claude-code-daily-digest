Andrej Karpathy Skills

230.8k stars, +3,030 this week. A single CLAUDE.md + plugin distilling four principles Karpathy described about LLM coding failures: Think Before Coding (surface assumptions, ask when unclear), Simplicity First (write only what the problem needs), Surgical Changes (touch only what the request requires, match existing style), and Goal-Driven Execution (define verifiable success criteria, loop until they pass). MIT, 23k forks. Also ships a Cursor `.mdc` rule. Not affiliated with Karpathy or Anthropic.

OmO (oh-my-openagent)

70.8k stars, updated Nov 8. Type "ultrawork" (or "ulw") anywhere in a prompt and OmO reads the codebase, plans, verifies each step, and stops only when done. Add "mass ulw" and it decomposes the job into a graph of parallel agents on different models — routing simpler work to cheaper ones automatically. Kibitzer memory stores mistakes in a git repo of Markdown files so a cheap background model can flag repeated errors. Works with Claude, ChatGPT, Kimi, and GLM subscriptions via `/login`. Config in `~/.omo/omo.jsonc`.

AutoHarness

10.8k stars. A Claude Code plugin that grows your skill library from real sessions: each episode is distilled into a skill with `/learn`, similar ones are merged, and skills that stop being loaded get pruned. Crucially it only touches skills it created — your hand-written config and installed plugins are left alone. Each create/update is logged in an evidence ledger. Requires Python 3.11+ on `python3`. Behavior tuned via `AUTOHARNESS_*` env vars.
