Context Mode

34k stars and an HN front-page hit (538 points). A free, local plugin that intercepts large tool outputs—file reads, shell, web fetches—stores them in a per-project SQLite FTS5 index, and returns only what the agent actually asks for. Benchmarks across 36 real tasks show a median 99.4% byte reduction vs. dumping raw output into the context window.

Reticle

1.3k stars, Show HN hit. Adds a tiny dev-only SDK so your Claude Code (or Cursor/Codex) agent can drive the running app and read what happens inside it—network responses, state, console errors, the source line behind each UI element. Returns a pass/fail/cannot-tell verdict per check with file:line evidence. Saves verified flows that gate CI without needing an AI model.
