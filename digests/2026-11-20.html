Claude Code v2.1.328–2.1.329

Two back-to-back releases landed November 19. v2.1.328 brings Auto mode to Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway — plus `"onFailure": "block"` for `mcp_tool` hooks and a tighter `/code-review` (bugs and CLAUDE.md violations only; use `/simplify` for cleanup). v2.1.329 adds `/tasks` showing all scheduled tasks and `/loop` wakeups with one-key stop, OpenTelemetry while Code Mode is on, and a trust dialog showing exactly where a folder's hooks are declared.

Tiny macOS notch app that monitors Claude Code, Codex, Cursor, and Gemini CLI — surfaces agent permission requests in the notch and lets you approve them from your iPhone lock screen. 7.4k stars. Also supports Windows 10/11, Linux (AppImage/.deb/.rpm/NixOS), and Android 11+. MIT (code), by Louis Raillé.

Earshot

MCP server and CLI that gives coding agents ears and a voice: describes what a sound file contains in words, matches audio to text descriptions, locates moments in long recordings, checks whether audio is real or synthesized, reviews films with a listening transcript, and generates sounds from code recipes. Ships 252 built-in SFX. CPU-only (~1.1 GB model download), MIT, 5.3k stars.

Floorplan

Claude or Codex reads your codebase and draws an interactive, plain-English map of it — no config, no embeddings, no vector store. Output is a navigable HTML file showing files, functions, and their relationships. 5.5k stars, MIT, by Hayden Smith. Node 18+ required; also works with Codex.

plugin · viral · marketplace
claude plugin marketplace add haydenschmitty/floorplan && claude plugin install floorplan@floorplan
