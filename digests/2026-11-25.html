Claude Code v2.1.332 — Skills from MCP Servers (Beta)

Anthropic shipped v2.1.332 today, adding Skills from MCP servers in beta — MCP servers now push skills directly into Claude Code's `/` slash menu as `server:skill` entries, no manual installs needed.
